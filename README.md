# 🚀 TypeScript Basics

## 📖 What is TypeScript?

TypeScript is a **superset of JavaScript** that adds **static typing** to the language. It compiles to plain JavaScript, making it compatible with any JavaScript environment.

## ✨ Key Features

- **🔒 Static Typing**: Catch errors at compile-time instead of runtime
- **🛠️ Enhanced IDE Support**: Better autocomplete, refactoring, and navigation
- **📚 Object-Oriented Programming**: Classes, interfaces, and modules
- **🔧 Modern JavaScript**: Supports all ES6+ features plus future proposals
- **🌐 Cross-Platform**: Runs anywhere JavaScript runs

## 🔢 Basic Types

TypeScript provides several basic types:

- `number`: For numeric values (e.g., `let age: number = 25;`)
- `string`: For text (e.g., `let name: string = "John";`)
- `boolean`: For true/false (e.g., `let isActive: boolean = true;`)
- `array`: For collections (e.g., `let numbers: number[] = [1, 2, 3];`)
- `tuple`: Fixed-length arrays with specific types (e.g., `let person: [string, number] = ["Alice", 30];`)
- `enum`: For named constants (e.g., `enum Color {Red, Green, Blue}`)
- `any`: Opt-out of type checking (use sparingly!)
- `unknown`: Safer alternative to `any`
- `void`: For functions that don't return a value
- `never`: For functions that never return (e.g., throw errors)
